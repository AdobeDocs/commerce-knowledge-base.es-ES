# Adobe Commerce en la infraestructura de la nube: Compruebe la configuración de CPU del host

El artículo adjunto proporciona directrices detalladas sobre los pasos y las consultas que un usuario puede seguir para comprobar la configuración de CPU de un host. El usuario puede aplicar estos pasos para identificar un cambio de tamaño, localizar el momento del cambio y ver todos los cambios de configuración de hardware que se produjeron, si los hubo, en cualquier momento antes o después del cambio de tamaño.

## Productos y versiones afectados

Adobe Commerce en cloud Infrastructure 2.3.x, 2.4.x
